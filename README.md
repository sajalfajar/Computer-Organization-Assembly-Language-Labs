# Computer Organization and Assembly Language

This repository contains my Computer Organization and Assembly Language (COAL) lab tasks and practice programs.

## About

The labs here cover low-level programming concepts, including how a processor works with registers, memory, and instructions. The goal is to understand how high-level code is executed at the hardware level.

## Topics Covered

- Number systems and data representation
- CPU registers and memory organization
- Data movement instructions (MOV, PUSH, POP)
- Arithmetic and logical instructions
- Flags and conditional jumps
- Loops and branching
- Arrays and strings
- Procedures and the stack
- Input and output using interrupts

## How to Run

Assembly programs need an assembler and an emulator or runtime. Common options include:

- **emu8086** for 8086 assembly programs
- **MASM / TASM with DOSBox** for DOS-based assembly
- **NASM** for x86 programs

Open the program file in your assembler, assemble it, and then run it. The exact steps depend on the tool used in your course.
